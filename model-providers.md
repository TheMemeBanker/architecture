# model providers

the LLM providers the framework connects to, unlocking advanced capabilities across agents and semantic applications.

| provider | typical use |
|---|---|
| anthropic | frontier reasoning and agentic workloads |
| deepseek | cost-efficient open-weight reasoning |
| gemini | multimodal understanding and long context |
| ollama | local and self-hosted open models |
| openai | general-purpose completion and embeddings |
| perplexity | search-grounded answers |

provider-agnostic by design: agents declare capabilities, not vendors — swap providers without rewriting the agent.
