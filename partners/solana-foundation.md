# solana foundation

`ecosystem_partner` · `grant`

arc is partnering with solana foundation to accelerate AI innovation on the solana network. leveraging rig — arc's rust-based framework for building high-performance AI agents — this partnership aims to streamline on-chain workflows, boost developer tooling, and foster novel user experiences on solana.

## what's happening

- **targeted rfps** — arc will publish requests for proposals calling for ai-powered solana applications: agent-based trading, defai applications, defi workflows, developer tooling, or any creative new approach that highlights solana's speed and adaptability
- **arc grants** — selected teams receive resources and grants directly from arc to accelerate development
- **high-impact deliverables** — reusable "rig agent toolkits" that handle automated trading flows, nft management, or contract calls on solana, complete with clear docs and open-source code merges

## timeline & oversight

- arc handles rfp creation, developer outreach, and milestone tracking
- selected teams receive technical mentorship from the solana foundation

## success indicators

1. **on-chain activity** — growth in transactions and protocol usage from rig-based AI agents running on solana
2. **dev adoption** — uptick in rig developer activity (github forks, stars, and usage in new solana-centric projects)
3. **tooling quality** — positive community feedback on the agent toolkits, documentation, and best practices

rust developers, AI enthusiasts, and solana builders: submit proposals when the rfps drop — selected teams receive arc funding, mentorship, and the opportunity to shape the next wave of AI applications on solana.
