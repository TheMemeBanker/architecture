# rig framework

the foundational rust-based system for building and orchestrating powerful, lightweight AI agents. it provides core libraries, multi-agent support, and on-chain integrations.

→ [view rig repository](https://github.com/0xPlaygrounds/rig)

## core library

essential utilities to create AI agents, manage prompts, handle embeddings, and maintain robust performance.

## multi-agent & extensibility

supports orchestrating multiple agents, embracing wasm for edge deployment, integrating with blockchains, and storing context in vector databases.

### real-world projects

demonstrates how multi-agent architectures are applied to real use cases, from data pipelines to on-chain governance.

### wasm & edge deployments

enables AI agent deployment on edge devices for low latency and minimal resource overhead.

### on-chain integrations

connects agents to solana, arbitrum, or other networks for reading on-chain data and executing smart contracts.

### AI memory & vector stores

provides intelligent memory systems for advanced AI features and continuous context retention.
