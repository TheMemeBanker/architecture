# fabelis AI

`token_live` · `AI_layer` · `onchain` · `handshake`

## origins

[fabelis](https://fabelis.ai/) began as an AI agent framework built on [rig.rs](https://github.com/0xplaygrounds/rig) to extend its functionality into social media agents, storytelling, narration, and a new platform for open-source collaboration in the rapidly evolving AI space fostered by arc. its inception was inspired by the need for a versatile and scalable framework that could seamlessly integrate with various AI applications while maintaining an open-source ethos.

## evolution

over time, the vision for AI agents expanded beyond simple personality-driven interactions to equipping agents with powerful tools capable of executing meaningful tasks autonomously. recognizing this shift, fabelis evolved to adopt the [model context protocol](https://modelcontextprotocol.io/introduction) (mcp), a pioneering standard that exposes an api layer to AI agents — allowing agents to perform complex tasks efficiently across domains, from managing social media presence to facilitating collaborative projects.

## the fabelis framework

- **[mcp-core](https://github.com/fabelis/mcp-core)** — the backbone of fabelis, implementing the mcp client/server model. it extends the core functionality of rig to accommodate the model context protocol, providing a robust and scalable environment for deploying AI agents capable of handling diverse tasks.
- **[agent](https://github.com/fabelis/agent)** — an opinionated extension and adaptation of rig, focusing on enhancing agent capabilities with additional features and integrations. it allows developers to rapidly build and deploy agents optimized for specific use cases, leveraging the power of mcp.

fabelis is built with a strong emphasis on community collaboration — developers are encouraged to contribute ideas and improvements through pull requests.
